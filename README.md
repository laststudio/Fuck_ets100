## 🎯 这个软件干什么的

**Fe (Fuck ets100)** 是一款专门针对**科大讯飞 e听说（ETS 100）**用户打造的现代化答案提取与作业辅助工具 📖

无需繁琐复杂的操作，Fe 能够全自动解析并提取 e听说 中的试卷试题与官方标准答案，让你不用打开官方 App 也能随时查阅完整解析，告别低效作业负担 👀

### 核心功能特性：
- 📚 **全题型作业答案一键读取**：一键解析提取 e听说 试卷题目、听力原文及标准参考答案。
- ☁️ **官方云端直连模式**：支持直接使用畅言/ETS100 账号云端登录，免文件访问权限、免 Root 即可直接拉取作业列表与答案解析。
- 🔍 **全题型深度覆盖**：全面支持听选信息、回答问题、信息转述、短文朗读、模仿朗读及全真模拟考试等丰富题型。
- ⚡ **本地免 Root 兼容技术**：独创支持**零宽字符直读**，兼容 **Shizuku** 提权与 Root 直读，各类 Android 机型均能完美适配。
- 💻 **多端协同互通**：除 Android App 外，LastStudio 还同步提供 [Fe Web 网页版](https://fe-web.lastudio.cc)，电脑或浏览器端免安装即开即查。
- 📱 **纯净操作体验**：点开即用、无广告植入，原生支持 Material You / 动态深色模式，护眼舒适。

## 🚀 极速上手教程

### 第一步：获取应用安装包

1. 推荐前往 **[LastStudio 官方极速下载通道](https://lastudio.cc/download?app=fe)** 获取最新 APK（免登录、CDN 节点高速不限速直链）；
2. 亦可在 [GitHub Releases 页面](https://github.com/laststudio/Fuck_ets100/releases) 或 [网盘分流](https://oplist.lastudio.cc/Fe_release) 下载；
3. 下载完成后安装至 Android 手机（若系统提示“允许安装未知来源应用”，授权通过即可）；
4. 打开 **Fe (Fuck ets100)** 应用。

---

### 第二步：选择最适合你的读取方式

根据你的设备环境与权限情况，对照下表即可轻松选择：

| 模式 | 推荐等级 | 适合场景 | 权限要求 |
| :--- | :---: | :--- | :--- |
| **☁️ 云端模式** | ⭐⭐⭐ **最推荐** | 想直接获取最新作业与试卷，不想折腾手机本地存储权限 | **零特殊权限**（无需存储/悬浮窗） |
| **✨ 零宽字符直读** | ⭐⭐ **轻量便捷** | 想直接读取手机本地已下载的作业，且设备系统支持该漏洞接口 | 基础无障碍/本地读写 |
| **🧩 Shizuku** | ⭐⭐ **稳定可靠** | 零宽字符不兼容的系统，已安装配置好 Shizuku 服务 | Shizuku ADB 授权（免 Root） |
| **🔓 Root 模式** | ⭐ **极客可选** | 手机已获取 Root 权限（Magisk / KernelSU / APatch） | Superuser Root 权限 |

**速选指南：**
- **追求简单省心**：直接使用 **云端模式**（最推荐，免权限）；
- **想查看本地已离线作业**：优先尝试 **零宽字符直读**；
- **零宽字符不可用**：使用 **Shizuku** 模式；
- **已 Root 设备**：可直接使用 **Root** 模式读取。

---

### 第三步：按选定模式配置授权

#### ☁️ 模式一：云端模式（推荐）
1. 进入应用底部 **“设置” → “运行授权”**；
2. 选择 **“云端模式”** 并点击 **“登录 ETS100 账号”**；
3. 输入手机号与密码完成认证（或通过畅言扫码网页登录）；
4. 返回主界面 **“读取”** 页面，点击右下角 **“读取”** 按钮；
5. 确认安全提示后，等待云端作业列表刷新；
6. 点击目标作业任务，稍候片刻即可完成完整答案解析。

> ⚠️ **温馨提示**：云端模式直接访问官方接口，读取期间请勿在官方 e听说 App 中进行正在录音、考试或提交操作，避免异地登录引起状态变动。

#### ✨ 模式二：零宽字符直读
1. 进入 **“设置” → “运行授权”**，选择 **“零宽字符直读”**；
2. 按照屏幕引导完成系统授权；
3. 返回 **“读取”** 页面点击右下角按钮读取本地作业数据。
> *如提示“当前设备不支持”，请改用云端模式或 Shizuku 模式。*

#### 🧩 模式三：Shizuku 模式（免 Root）
1. 确保手机已安装并激活 [Shizuku](https://shizuku.rikka.app/) 服务；
2. 进入 Fe 的 **“设置” → “运行授权”**，勾选 **“使用 Shizuku”**；
3. 允许 Fe 请求的 Shizuku API 授权，回到读取页面点击 **“读取”**。

#### 🔓 模式四：Root 模式
1. 确认手机具备 Root 运行环境；
2. 在 **“运行授权”** 中选择 **Root 模式**；
3. 弹出超级用户弹窗时点击“允许”，随后在读取页面获取数据。

---

### 第四步：查阅、核对与导出答案

读取成功后，所有试卷作业将整齐排列在列表清单中 📋
- 点击任意一份作业，即可查看题目详情、听力音频文本与标准答案解析 🎉；
- 支持多种题型的答题提示、重点词汇标注与参考范文；
- 若出现未读出情况，请检查：
  - e听说 官方应用内该份作业资源是否已下载完全；
  - 授权模式是否正常激活生效；
  - 云端登录会话是否过期，或更新至最新版本重试。
